Learning Reflection

As for my reflection in this course, it was deeply a meaningful challenge to make a webpage of your own. I still remember the time listening to our professor explain the basic information of HTML and CSS. Now, we've gone from those everyday lecture and laboratory examples to actually implementing a real, functional website coming from my idea.

During development, it feels hard to start at the part where all you can see from your website is blank. With the help of AI tools and Design Layout tools, I was able to execute the design I wanted.

The difficult part of the website was figuring out how we were going to make the website responsive. I would try to fix a layout for the mobile view, and suddenly my interactive 3D flip cards on the desktop view would stretch into weird shapes because of old styling rules. To fix this challenge, I was able to clean the styling of my website by separating each section into their designated file: one for the navbar, one for the hero section, one for the ID cards, and a separate one just for the mobile view.

This problem in the styling is only like the peak of an iceberg because I found out that my website couldn't catch data yet. That's why I implemented a feature wherein the user who will contact me or send a message to my email will be stored in the database. It was quite a headache since I'm still not highly skilled in the backend part. By fixing this problem, I had to stop guessing and actually figure out why my code was failing silently. At first, my JavaScript was swallowing the errors in the background, so I wasn't even getting a warning. I changed my code to print the PHP responses directly into the browser console and this eventually showed me the problem. I was making two big rookie mistakes; first was trying to run my files directly from my hard drive instead of using a local server, and secondly, my database connection was using the default port 3306 while my local MySQL server was running on port 3307. Once I moved the project into my server folder, ran it through localhost, and updated my db-config.php file to the correct port, the connection finally clicked and the data flowed perfectly into my contact_messages table.

Overall, one of the biggest things I realized is just how much patience you need to become a programmer. This feeling isn't exactly new to me, since I experienced similar pressure during our capstone project. However, going through it again made me realize that the amount of effort you put in directly impacts the quality of your output. No matter how hard a mistake is to find, your effort will eventually pay off.
